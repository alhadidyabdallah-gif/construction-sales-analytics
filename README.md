# 🏗️ Construction Sales Analytics Dashboard

## 📊 Project Overview
An end-to-end data analytics project analyzing **3 years of sales data** for a mid-sized construction company operating in Saudi Arabia.

## 🎯 Business Problem
The company had:
- Sales data scattered across multiple systems
- No visibility into top-performing clients and products
- Difficulty tracking budget vs. actual sales

## 🛠️ Tools & Technologies
- **MySQL:** Database design, 4 interconnected tables (Star Schema)
- **SQL:** Advanced queries (JOINs, CTEs, Window Functions, ABC Analysis)
- **Power BI:** Data modeling, DAX measures, Interactive Dashboard
- **Data Storytelling:** Executive summary with actionable recommendations
